# An episode, without the video frame

The same player with kind="audio": no picture area, the controls carry the whole component. Reaching for a second component here would double the keyboard surface for no gain.

## Usage

```tsx
import {MediaPlayer} from "@aurea-uds/react";
```

```tsx
<MediaPlayer kind="audio" title="Episode 12 · Design tokens" subtitle="42:10" src="/ep12.mp3" />
```
