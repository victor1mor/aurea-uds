# A colour stroke on top

A stroke on the top edge in the tone's fill colour, the same in both themes. It is decoration: the title already says the subject.

## Usage

```tsx
import {Card} from "@aurea-uds/react";
```

```tsx
<Card accent="success">
  <span className="muted">Fuel</span>
  <strong>3 days ago</strong>
</Card>
```
