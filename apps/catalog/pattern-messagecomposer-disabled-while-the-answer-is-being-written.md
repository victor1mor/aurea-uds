# Disabled while the answer is being written

Sending twice is the mistake to prevent. Disabling the composer says the turn is not yours yet, which is clearer than a spinner somewhere else on the screen.

## Usage

```tsx
import {MessageComposer} from "@aurea-uds/react";
```

```tsx
<MessageComposer disabled={pending} placeholder="Waiting for a reply…" onSend={post} />
```
