# Showcase

What is built with Aurea today, and how to get your project listed here.

## This site

The site you are reading is built only with Aurea. Every page, from the header and the side navigation to the code blocks and the live examples, uses the same components and tokens that are published on npm.

This is enforced, not just intended: a check in the repository fails the build when the site imports anything from outside Aurea or loads a resource from another address. When the site needs a piece that does not exist, the piece is created in Aurea first.

Use the theme switch in the header to see every page in light and in dark.

## Blocks

The [Blocks](./blocks.html) area holds ready sections, larger than a pattern and smaller than a screen: sign-in panel, settings form, members table, stats row, pricing row, activity panel, analytics workbench, media library and more. Each one is built with the components of this site, and its code is on its page.

## Patterns and recipes

- [Patterns](./patterns.html): components already assembled in one specific way, ready to copy.
- [Recipes](./recipes.html): product archetypes, with the patterns to use and the rules to hold for a whole kind of application.

## Your project here

Built something with Aurea and want it listed? [Open an issue on GitHub](https://github.com/victor1mor/aurea-uds/issues) with the name, a link and one sentence about it.

Only public projects are listed, and only with the owner's permission.
