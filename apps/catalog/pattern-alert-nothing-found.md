# Nothing found

The empty result of a filter: says why it is empty and offers the way back.

## Usage

```tsx
import {EmptyState, Button} from "@aurea-uds/react";
```

```tsx
<EmptyState icon="magnifying-glass" title="No results"
  description="No component matches that filter."
  action={<Button variant="outline">Clear filters</Button>} />
```
