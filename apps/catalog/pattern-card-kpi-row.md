# KPI row

Three numbers of the same weight. One line, equal columns, trend beside the value.

## Usage

```tsx
import {KPI} from "@aurea-uds/react";
```

```tsx
<KPI label="Revenue" value="$48.2k" trend="+12%" />
<KPI label="Churn" value="1.8%" trend="-0.3%" />
<KPI label="Seats" value="312" trend="+18" />
```
