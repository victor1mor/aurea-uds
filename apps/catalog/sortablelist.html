SortableList

Reorder by dragging — and by keyboard, which is the reason it may exist at all.

SourceStyles source

Usage

import {SortableList} from "@aurea-uds/react";

Reorder by dragging with mouse, touch or pen — and by keyboard, which is not an extra here: without it the component would not ship. Space picks up, arrows move, Space drops, Escape puts it back, and every step is announced.

  • Draft
  • In review
  • Published
Press Space to pick this up, then Arrow Up and Arrow Down to move it. Space drops it, Escape puts it back.
const [items, setItems] = useState([
  {id: "a", label: "Draft"},
  {id: "b", label: "In review"},
  {id: "c", label: "Published"},
]);

<SortableList
  label="Pipeline stages"
  items={items}
  onReorder={(from, to) => setItems(prev => {
    const next = [...prev];
    next.splice(to, 0, ...next.splice(from, 1));
    return next;
  })}
/>

API Reference

SortableList props
PropTypeDefaultDescription
itemsArray<{id, label}>—The rows, in the order they are shown. Data and not children, the same idiom as Timeline, Stepper and Sidebar.
onReorder(from: number, to: number) => void—Called with the two indexes. The list is controlled and keeps no order of its own — the keyboard path and the pointer path call this same callback, so there are never two sources of truth about the order.
labelstringSortable listAccessible name of the list.
