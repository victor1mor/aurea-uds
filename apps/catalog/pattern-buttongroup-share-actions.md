# Share actions

Glyph-only set at the end of a card: one name for the group, one for each action.

## Usage

```tsx
import {ButtonGroup, IconButton} from "@aurea-uds/react";
```

```tsx
<ButtonGroup label="Share">
  <IconButton icon="link-simple" label="Copy link" />
  <IconButton icon="envelope-simple" label="Send by e-mail" />
  <IconButton icon="download" label="Download" />
</ButtonGroup>
```
