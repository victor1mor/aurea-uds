# A shortcut inside a sentence

Prose is where the keyboard is taught. Marking the keys instead of quoting them means a screen reader announces them as keys, and the reader can tell `Esc` the key from "esc" the word.

## Usage

```tsx
import {Kbd} from "@aurea-uds/react";
```

```tsx
<p>Press <Kbd>Esc</Kbd> to close, or <Kbd>⌘</Kbd> <Kbd>K</Kbd> to search.</p>
```
