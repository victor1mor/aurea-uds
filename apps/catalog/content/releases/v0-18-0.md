`Progress` can run without a total, `Grid` accepts named column minimums, `NavList` shows avatars and small indicators, and `AppShell` gets a button to collapse the sidebar. Component metadata now lists the Phosphor icon names each component actually draws. Nothing was removed or renamed.

## New

- **[`Progress`](./progress.html) without a total** (web and React Native): `value` is optional. Without it the bar is indeterminate: a 2/5 segment runs across in 1.5 s and `aria-valuenow` (`now` in React Native) is omitted. Before, it showed 0% and looked stuck. With reduced motion, the whole bar shows dimmed (`--opacity-disabled`) instead of a moving segment.
- **`Progress` `detail`**: supporting text at the top right, small, medium weight, muted, with equal-width digits. As text it goes into `aria-valuetext` (for example "64%, 2.3 MB/s"), so it is heard once.
- **`Progress` `tone`**: `brand` (default), `neutral`, `success`, `warning`, `danger`, `info`. Paused is `neutral`; failed is `danger`.
- **[`Grid`](./grid.html) `min` by name** (web; `minColumnWidth` in React Native): `xs` 8rem, `sm` 12rem, `md` 15rem (default) and `lg` 20rem. Written sizes still work. Before, `min="sm"` passed the type check but produced a single column.
- **[`NavList`](./navlist.html) `avatar` and `indicators`** (web and React Native): `avatar` takes the place of the icon; `indicators` (`[{icon, label}]`) adds small muted signs before the value, such as pinned or muted, and each `label` is what screen readers hear.
- **[`AppShell`](./appshell.html) `sidebarCollapsible`**: draws a button at the top of the seam between the menu and the content, and collapses the sidebar on its own between 1024 and 1279 wide. `defaultSidebarCollapsed` and `onSidebarCollapsedChange` complete the controlled and uncontrolled pair. Without the prop, the shell is unchanged.
- **New strings**: `sidebarCollapse` and `sidebarExpand`, the labels of the collapse button.

## Fixed

- **A collapsed sidebar drawer was a rail of unnamed icons.** Below 1024, with `sidebarCollapsed`, the drawer opened as a rail with names hidden. The drawer is now never a rail, controlled or not.
- **In right-to-left writing the content touched the page edge** and left a 32 gap at the seam, because the `.content` margin was physical. It is now logical; left-to-right is unchanged.
- **The `BottomNav` entry** did not list `capsule` and `expand` in the `indicator` type, and still said every indicator shows the label.
- **Component icon metadata**: 19 old icon names in 12 component entries were replaced with the Phosphor names the code draws, and 22 entries that were missing icons now list exactly what the component draws.
- **The contract** (`aurea.contract.json`) now names Atkinson Hyperlegible Next and Mono and Phosphor as the brand fonts and icons, and describes the icon button as round.

## Breaking changes

- **`AureaStrings` has two new keys**: `sidebarCollapse` and `sidebarExpand`. If you build a complete object of this type, add them. Passing a partial object to `AureaProvider` needs no change.
