`Topbar` is now called `Header` on both targets, and the old name keeps working. On the web, `Header` becomes a site header with navigation links and a mobile menu, and `Section variant="footer"` builds a site footer. Nothing was removed.

## New

- **Site header: [`Header`](./header.html) with `items`** (web): the same item list as `Sidebar` and `BottomNav`. `current` marks the current page with `aria-current="page"`, the accent color and medium weight; `actions` sits on the right; `maxWidth` aligns the bar with the page `Container`. The bar is 64 tall (`--topbar-height`).
- **Mobile menu**: below 768 the links leave the bar and drop into a panel right under it, as wide as the bar, opened by a button. The panel is a native popover (`<nav popover="auto">`), with no JavaScript, so `Header` stays a server component. Escape and tapping outside close it, and Escape returns focus to the button when the panel was opened by keyboard.
- **Menu id**: the panel id is fixed (`aurea-header-menu`); a page with two site headers passes a `menuId` to each.
- **Known limits**: in apps with client-side routing the panel does not close on navigation, so give `Header` a `key` that changes with the route. In WebKit, after clicking the button, Escape closes the panel but focus goes to the page.
- **Site footer: [`Section`](./section.html) `variant="footer"`** (web): a `<footer>` with the brand (`brand`), link columns with titles (`links`) and a legal line (`legal`), inside a `Container`. It inherits the section background, spacing and theme (a dark footer on a light page is `theme="dark"`). On phones everything stacks; on desktop the columns share the width.

## Changed

- **`Topbar` is renamed `Header`, on the web and in React Native.** `Topbar` remains as the same component, marked as the old name, with identical markup. Types follow: `HeaderVariant` and `HeaderProps` on the web, `AureaHeaderVariant`, `AureaHeaderInset` and `HeaderProps` in React Native; the old type names still work. The `.topbar*` classes and the `AppShell` props (`topbarVariant`, `topbarDivider`) are unchanged.

## Fixed

- **Site header links wrapped to a second line** between 768 and 1023 wide without `maxWidth`, growing the bar from 64 to 80. The `AppShell` bar rule also matched the site header's `nav`. The links now stay on the brand's line.
