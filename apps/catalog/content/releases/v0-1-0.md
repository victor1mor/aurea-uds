The first public release of Aurea UDS. The design system ships as six packages, and the numbering starts at `0.1.0`.

## New

- **`@aurea-uds/tokens`**: the design tokens.
- **`@aurea-uds/core`**: the stylesheet, imported as `@aurea-uds/core/css`.
- **`@aurea-uds/icons`**: the icon set (Carbon icons).
- **`@aurea-uds/fonts`**: the typefaces (IBM Plex).
- **`@aurea-uds/react`**: the React components, built on Base UI (`@base-ui/react`).
- **`@aurea-uds/contracts`**: the machine-readable contracts that describe the components.
