Every app using Aurea gets new neutral and status colors in both themes; the brand yellow stays the same. Status fills are now identical in light and dark, and text on the screen uses a separate `-400` color. This release also ships v0.26.0 (category colors for `Badge`, a `KPI` that shows direction) and v0.26.1 (the React Native `DatePicker` in the browser). No props changed and nothing was removed.

## Changed

- **New neutrals.** Light: background `#f5f5f5`, white cards, text `#242424`, muted text `#616161`, borders `#e0e0e0`. Dark: background `#1f1f1f`, cards `#292929`, white text, muted text `#adadad`, borders `#525252` (lighter than before, with more visible borders).
- **New status colors.** Green `#107c10`, orange `#f7630c`, red `#c50f1f` and blue `#0078d4` as solid fills, the same in both themes. Text on them is white; on orange, dark.
- **Fill and text are separate tokens.** `--success`, `--info`, `--warning` and `--destructive` are the solid fill. Text, icons, borders and bars on the screen use the `-400` pair, tuned per theme: outline and ghost buttons, `Status`, the alert icon, `LogStream` and the `Progress` bar. Web and React Native.
- **The solid status badge matches the solid button** of the same tone (same color, same text color), on the web and in React Native. Category, brand and neutral badges are unchanged.
- **Sidebar group labels** go from 62% to 72% of the sidebar text color, for contrast in the light theme.
- **Contrast**: every text role passes 4.5:1 on all five surfaces of each theme.

## Breaking changes

- **If your app paints text with a status fill**, switch to the text tokens: `--success-400`, `--info-400`, `--warning-400` and `--danger-400` instead of `--success`, `--info`, `--warning` and `--destructive`. In the dark theme the fill used as text gives only 2.4 to 3.6:1.
- **React Native**: use `t.color.success400` (and its siblings) for text, and `t.color.success` for fills.

## Includes v0.26.1

### Fixed

- **React Native in the browser: [`DatePicker`](./datepicker.html) now opens the browser's date picker.** The date library has no web version, so nothing opened. Now the browser's own `<input type="date">` (or `type="time"`) sits invisibly on top of the Aurea trigger: the look stays Aurea's, touch and screen readers use the browser field, and the calendar follows the Aurea theme.
- **How it opens**: on desktop a click calls `showPicker()`; inside a page from another origin, where Chrome refuses that call, the field's own icon, stretched over it, opens it. The `Field` label and error reach screen readers. Android and iOS are unchanged.

## Includes v0.26.0

### New

- **Category colors on [`Badge`](./badge.html)** (web and React Native): eight named colors, `red`, `orange`, `green`, `teal`, `cyan`, `blue`, `violet` and `pink` (`variant` on the web, `tone` in React Native). They mark a group, not a state. Yellow is left out because it belongs to the brand.
- **Category badge details**: they work in all three emphases (`soft`, `solid`, `outline`) and pass 4.5:1 in both themes and both brands. Neighboring hues alternate two lightness levels, so they are not told apart by hue alone. New types: `BadgeCategory` (web) and `AureaBadgeCategory` (React Native).
- **Tokens `--category-<color>` and `--category-<color>-bg`** (32 in total, dark and light): the accent and soft background of each category. They do not change with the brand.
- **[`KPI`](./kpi.html) direction** (web and React Native): `direction` (`up`, `down`, `flat`) draws an arrow, colors the trend and adds a word for screen readers. `tone` (`success`, `danger`, `neutral`) flips the color when going up is bad; without `direction`, `tone` paints nothing.
- **KPI labels and layout**: `directionLabel` replaces the spoken word (default in English: "Up", "Down", "No change"). The arrow stays on the first line when the trend wraps.
- **KPI without a box**: `variant="plain"`, for a number inside a card that already exists.
- **New KPI types**: `KPIProps`, `KPIDirection`, `KPITone`, `KPIVariant` (web) and `AureaKPIDirection`, `AureaKPITone`, `AureaKPIVariant` (React Native).
- **New catalog patterns**: a summary box built from `Card`, `Stack`, `Cluster` and the `check` icon; badge categories; KPI direction and KPIs inside a card.

### Changed

- **React Native `KPI` matches the web**: the number goes from `2xl` (24) to `3xl` (30), and the trend from 14 to 16. With `direction`, the accessible name is built from label, number, direction word and trend, because the arrow is a drawing. Apps register the `trend-up`, `trend-down` and `minus` glyphs, like any icon.
- **The KPI inner gap comes from a token** (`--space-1`, 4) instead of a raw `5px`, on both targets.
- **On the web the KPI arrow is drawn in CSS** (the Phosphor icon as a mask), so the KPI stays plain markup with no JavaScript in the browser.
- **The contract** now allows the eight category colors as an exception to the "no alternative palettes" rule.
