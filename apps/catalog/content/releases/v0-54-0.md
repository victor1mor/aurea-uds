New options on web components — nothing changes unless you use them. One addition reaches React Native too: `SegmentedControl selectedStyle="emphasis"`.

## Breaking

- **New strings in `AureaStrings`:** `copy` ("Copy"), `codeBlockExpand` ("Expand code") and `codeBlockCollapse` ("Collapse code"). If you build the whole strings table by hand instead of starting from `defaultStrings` or `ptBR`, add them.

## New

- **`CodeBlock previewLayout="stacked"`** — the example box with the preview on top (350 tall) and the code under it. Past five lines the code starts collapsed at 150, fading out, with **Expand code** at the bottom (it becomes **Collapse code** once open). On plain HTML pages, `aurea.js` opens and closes it through `data-aurea-code-expand`. The default, `"tabs"`, is unchanged.
- **`CodeBlock filename`** — a 52-tall head with the file name and, with `copyable`, a written **Copy** button; a long line wraps instead of scrolling.
- **`Stepper variant="path"`** — 50 dots on an 8 track, the chosen one inverted and 56, with `startContent` and `endContent` at the ends. **`variant="bar"`** — one 12-tall segment per step, a link (`items[].href`) or a button, green when done.
- **`CommandPalette size="lg"`** — the large search: a 1024 window, a 64 field with Esc inside, **`filters`**, group titles with counts, 50-tall items with a tinted icon (**`items[].tone`**) and **`items[].description`**, **`preview`** (hidden below 1240) and **`footer`**.
- **`SegmentedControl`** — **`items[].icon`** (the selected one switches to the filled glyph), **`size="2xl"`**, **`wrap`**, **`orientation="vertical"`**, and a seventh **`selectedStyle`**, **`"emphasis"`**: the raised capsule with the emphasis letter and no line (web and React Native).
- **`RadioGroup variant="card"`** — each option is a whole card; the chosen one rises with a large shadow. **`indicatorPlacement="none"`** drops the dot.
- **`Checkbox variant="pill"`** — a capsule around the whole target; **`tone="success"`** paints the checked one as done.
- **`Alert appearance="soft"`** — the state colour at 14% behind the alert, no shadow, the body at 16 in the text colour. Under Aurea Ember it keeps the card skin.
- **`Card fill="brand"`** — the whole card in the brand colour with the ink on top. Under Aurea Ember it stays a regular card.
- **`Table striped`** — every other body row gets a fill, in both variants. **`Table variant="rows"`** — rows as capsules; a row with `data-selected` is highlighted.
- **`NavList size="lg"`** — 56-tall rows with a tinted icon (**`items[].tone`**); **`items[].current`** and **`currentLabel`** mark the current row.
- **`Toggle` and `ToggleGroup` `size="xl"`** (50), and **`Toggle area`** (`true` or `"pill"`) — a toggle that wraps a whole block.
- **`data-contained`** on a container keeps the dialogs, drawers and toasts inside it pinned to it instead of the window (in React, through `portalContainer` on `AureaProvider`).
- **`Accordion orientation="horizontal"`** — items stand side by side; the open one takes the row.
- **`KPI variant="brand"`** and **`bars`** / **`defaultBar`** — bars under the number, each one a button that shows its name and value.
- **`Toolbar tone="brand"`** — the yellow bar for bulk selection.

## Fixed

- **`Chart` on React Native** — the drawing with a name now announces itself as an image, so a screen reader reads the
  chart's name in the browser too. Nothing changes on screen.
