Aurea now ships thirteen palettes. The `lory` brand is renamed Aurea Ember, and eleven new brands join it. Read "Breaking" if you set `data-brand="lory"`, and "Look and feel" if you use the `Toolbar` or the dot on the `BottomNav`.

## Breaking

- **React Native: `AureaTokens` has a new `brand` field** (`AureaBrand | null`). Only code that builds an `AureaTokens` object by hand needs it.
- **`data-brand="lory"` is now `data-brand="ember"`.** Only the name changes; the colors stay. Replace it in your app: the old name no longer works, and a page that keeps it shows Aurea Gold.

## New

- **Eleven brands:** `data-brand="sun"`, `honey`, `orange`, `magenta`, `violet`, `indigo`, `cobalt`, `cyan`, `turquoise`, `emerald` and `lime`. Each one keeps Aurea's neutrals and redefines the primary color and the roles built on it: links, focus, the selected control, the sidebar and the selection. Aurea Orange moves the warning color to honey, so a warning never looks like the brand.
- **Aurea Ember takes the new styles** — `pressedStyle`, `selectedStyle`, the `Timeline` `variant` and `currentStyle` — like every other brand. Its default look does not change.
- **Brands in React Native:** `brand` on `AureaProvider` — `"ember"` or one of the eleven — with the same names as `data-brand`. `resolverTokens` takes the brand as its fourth argument, and the new `AureaBrand` type lists them. A `Card` with `variant="contrast"` keeps the brand.
- **The theme button on the site** lists the thirteen brands, and the Theming page has the table. The React Native pages follow the brand you pick.

## Look and feel

- **`Toolbar`** is 4 px from the buttons to its edge and 8 px between buttons (it was 7 and 6). The bar is 44 px tall instead of 50.
- **`BottomNav`:** the empty dot that means "something new" is red. On the current item, only a badge in the brand color is inverted, so a red counter stays red. On a bar in the brand color (`currentStyle="bar-*"`), the dot stays dark.
- **Aurea Ember, dark theme:** the `Switch` thumb, the `Slider` thumb, the `Checkbox` mark and the `Radio` dot are white, as in every other brand.
- **Brands, dark theme:** the label of the selected segment, tab and navigation item, and the `.eyebrow`, use `--primary-emphasis`. Aurea Gold looks the same.

## Fixed

- **The solid primary `Badge` in a brand** is filled with the brand color and its text color, like the primary button. It used the accent and could not be read on some brands.
