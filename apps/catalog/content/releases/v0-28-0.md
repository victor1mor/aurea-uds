Buttons can now share a link, with a "Link copied" message when the device cannot share. `Image` gains a generic phone frame, and the type scale gets an extra-bold weight and tabular numbers. Tables now align their digits.

## New

- **`share` on [`Button`](./button.html) and [`IconButton`](./iconbutton.html)** (web and React Native): if the browser can share the link (`navigator.canShare`), the device share sheet opens; cancelling is not an error. Otherwise the link is copied and a "Link copied" message appears attached to the button, with the button's own height, padding, type and capsule shape. Without `url`, the page address is shared.
- **Share failures and screen readers**: if copying fails, the button says so and shows the link selected, ready for Ctrl+C. The message is announced to screen readers.
- **Share on the web and in plain HTML**: in React, the message is the anchored `Toast`, managed by `AureaProvider`. In plain HTML, `aurea.js` does the same for `[data-aurea-share]`, through the new `window.Aurea.share`.
- **Share in React Native**: opens the system share sheet. On Android the link goes inside the message text, because Android drops the `url`. In the browser it follows the web behavior and shows the message through `ToastHost`.
- **[`Image`](./image.html) `frame="phone"`** (web and React Native): a screenshot inside a generic phone frame, with no notch, island or buttons. Outer corner 32, inner corner 24, 9/19.5 ratio by default. With a frame, class and style go to the frame.
- **Dark-theme screenshot**: `srcDark` on the web, `sourceDark` in React Native.
- **Heading and weight tokens**: `--font-heading` (for now the same font as body text) and `--weight-extrabold: 800`. The default heading stays semibold.
- **Atkinson Hyperlegible at weight 800**, shipped for both targets (12 KB on the web, downloaded only when used).
- **Typography props**: `weight="extrabold"` and `numeric` (equal-width digits) on `Text`, `Heading`, `Paragraph` and `Code`.
- **React Native typography**: `Text numeric`, `weight={800}` and the `heading` role. `fontFamilies` accepts `heading`; without it, headings use the `ui` map as before.

## Changed

- **Tables use equal-width digits** (web), so price and year columns line up. The number field does too. In React Native, the `KPI` number and the `Table` cells. Only digits change.
- **"Copied" is announced.** Copying from a code block (in `aurea.js` and in React) and from the `FileInput` receipt now tells screen readers "Copied"; before, only the icon changed.

## Fixed

- **React Native: status-toned text and the `Progress` bar used the background color.** `Text tone="success"` (and `danger`, `warning`, `info`) gave about 2.5:1 in the dark theme. They now use the `-400` text colors, like the web. Tones that are not status tones are unchanged.

## Breaking changes

- **`AureaStrings` has new keys.** Web: `copied`, `linkCopied` and `linkCopyFailed`. React Native: `linkCopied` and `linkCopyFailed`. If you build a complete object of this type, add them. Passing a partial object to the provider needs no change.
