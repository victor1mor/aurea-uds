## Added

- **A destructive item in web menus.** `destructive` on an action item of `DropdownMenu`, `ContextMenu` and `Menubar`, the same field React Native already had: the label and its icons turn the red of an error message (`--danger-400`), and the highlighted item takes the soft danger background (`--danger-bg`). Asking for confirmation before deleting is still up to your app.
- **`loading` on the React Native `Button`**, the same as on the web: the spinner takes the place of the leading icon, in the button's colour and the icon's size; the label stays, the press is blocked and the screen reader hears "busy". `IconButton` and `LinkButton` do not take it.
- **`disabled` on the web `FileInput`**: the drop area fades (`--opacity-disabled`), the file picker does not open and a dropped file is refused. The file input carries the HTML `disabled`. React Native already had it.

## Changed

- **Picking an option of a `radiogroup` closes the menu** on the web (`DropdownMenu`, `ContextMenu`, `Menubar`), as React Native already did. A `checkbox` item still keeps the menu open.
- **Menus and popovers fade out on React Native** (`DropdownMenu`, `Popover`), the same as on the web, in `durationFast`; they used to vanish at once. Nothing inside takes a touch while it fades, and with reduced motion it still closes at once.
- **The arrow of `Popover` and `Tooltip` has a fine point**, on the web and on React Native: two straight sides meeting at a tip, at the same size as before. It used to be a rounded curve.
