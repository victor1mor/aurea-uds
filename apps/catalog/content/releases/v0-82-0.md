## Changed

- **Continuous corners on the web.** Where the browser draws `corner-shape` (Chromium today), cards, dialogs, sheets, menus and every other rounded surface get the continuous corner the native package already has on iOS. The curve is `superellipse(1.65)` with the radius at 1.5 × the token (a card goes from 22 to 33), so it follows the same line as the iOS continuous corner of radius 22. Capsules and circles stay round. Where the browser does not draw `corner-shape`, nothing changes. The radius tokens do not change, so your own boxes that use `--radius-card` look as before.
- **`AppShell`: the collapse button is in the top bar, before the brand.** With `sidebarCollapsible`, the round arrow button at the seam between the sidebar and the content is gone; the shell draws `Sidebar.Toggle` at the start of the top bar instead, as `layout="sidebar"` already did. It is hidden below 1024px, where the drawer button opens the sidebar. The `.sidebar-toggle-slot` and `.sidebar-toggle` classes are removed from the stylesheet.
- **`AppShell`: no menu, no sidebar.** Without `navItems` (or with an empty list), `navigation` and `sidebarFooter`, the shell no longer draws an empty sidebar, nor the drawer or collapse button, and the content takes the full width. In `layout="sidebar"` the sidebar holds the brand, so it stays.
- **`CodeBlock`: bash commands are highlighted.** `highlightCode` gives the first word of every bash command (at the start of a line and after `|`, `&&`, `||`, `;`, `&` and `(`) the `tok-function` class, bold in the text colour. A variable assignment before the command, the `$` prompt and a continued line are not commands.

## Documented

- **`KPI`: keep a currency with its number.** The component does not change. The `value` description and a new example show how to join the currency symbol and the number with a no-break space (U+00A0) so they wrap together in a narrow column. `Intl.NumberFormat` with `style: "currency"` already puts one there.
