On the web, a loading [`IconButton`](./iconbutton.html) now shows only the spinner, centred, and a loading [`Button`](./button.html) replaces its leading icon with the spinner. This release also publishes v0.14.0, which adds new props to several React Native components and deprecates the `text-md` token.

## Fixed

- **`IconButton` with `loading`** showed the spinner next to the glyph, and in a 36-pixel button the spinner spilled outside. It now replaces the glyph and sits in the centre.
- **`Button` with `loading` and `leadingIcon`** showed the spinner, the icon and the text together. The spinner now takes the place of the leading icon, and the text stays.
- `ToolbarButton` uses `Button` internally and gets the same fix. Outside the loading state the button markup is unchanged. The React Native `IconButton` has no loading state and is unchanged.

## Includes v0.14.0

### New

- **[`Tabs`](./tabs.html) `variant="secondary"` (React Native)**: no capsule; a thin line under the whole row and a yellow line under the open tab. The row has the same height as the capsule. Without `variant`, or with `"primary"`, you get the capsule as before. New type: `AureaTabsVariant`.
- **`description` on [`Combobox`](./combobox.html) items (React Native)**: a second, muted 14-point line under the label. Screen readers read it as the item hint. Search still looks only at `label`.
- **[`NumberField`](./numberfield.html) `size="display"` (React Native)**: a large highlighted number, using the 30-point semibold heading size, the `controlHXl` height (which follows density), a 96-point width and the `lg` buttons. New type: `AureaNumberFieldSize`.
- **`icon` on `RadioGroup.Item` (React Native)**: an icon name shown before the text, at 24 with a 12-point gap, in the label colour. The selected option uses the filled shape when the registry has `<name>-fill`.

### Changed

- **`text-md` is now an alias of `text-sm`** (both are 14). It is marked `$deprecated` in the token file. Nothing changes on screen.
- **Deprecated**: `text-md` (and `textMd` in React Native) will be removed in 1.0. Use `text-sm` instead. Aurea's own CSS no longer uses the old name.

### Fixed

- **[`RadioGroup`](./radiogroup.html) description (React Native)** was 16, the same size as the label. It is now 14, matching `Checkbox` and `Switch`.
