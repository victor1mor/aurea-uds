This release adds two variations and one new name. [Section](./section.html) gets `variant="hero"`, the opening of a page, and [Banner](./banner.html) gets `variant="consent"`, a cookie notice with a preferences window. [Chip](./chip.html) is another name for [Badge](./badge.html). In the light theme, the accent text is now the brand yellow. [DependencyGraph](./dependencygraph.html) now honors `layer` and receives mouse clicks on nodes outside the editable mode, and the [Radio](./radio.html) dot is centered.

## New

- **`Section variant="hero"`**: the opening of a page. It takes an `eyebrow`, a `title` (the page's `h1`; use `titleAs="h2"` when it is not the first band), a `description`, `actions` (buttons, or a form with an e-mail field) and `media`.
- **`Section variant="hero"` layout**: with `align="start"` (the default) the media sits beside the text from 1024px; with `align="center"` everything is centered and the media goes under the text. On phones everything stacks. Children go after the actions.
- **`Section variant="hero"` title size**: 36px, then 60px from 768px and 72px from 1024px. The breakpoints are measured on the width of the band, not of the window, so a hero inside a narrow column keeps the smaller size.
- **Two text tokens**: `--text-6xl` (60px) and `--text-7xl` (72px), with `--leading-none`. In React Native, `t.size.text6xl` and `t.size.text7xl`.
- **`Banner variant="consent"`**: a cookie notice. It shows three buttons of the same weight: "Reject non-essential cookies", "Accept all cookies" and "Choose cookies". Rejecting is as easy to see as accepting.
- **`Banner variant="consent"` preferences**: "Choose cookies" opens a dialog with one switch per category (`categories`). Optional categories start off; required ones show "Always on" and have no switch.
- **`Banner variant="consent"` choice**: the choice reaches your app through `onConsent(choice, action)`. After it, a confirmation replaces the buttons and receives the focus. To let people change their choice later, show the notice again with `value` set to what you stored. Put it at the top of the page, before the skip link, and do not fix it to the screen. Web only.
- **`Chip`**: another name for `Badge`, on the web and in React Native. It renders exactly what `Badge` renders.

## Changed

- **The accent text in the light theme is the brand yellow**, the same as in the dark theme: `primary-emphasis`, `primary-outline`, `link` and `link-hover`. This covers the current sidebar item, links, the primary badge, the current page, the selected tag, the calendar and the secondary button. It measures 1.75:1 on the page background, a deliberate choice; before, it was a darker gold (`#826202`).
- **The focus ring in the light theme is the text color**: 14.24:1 on the page, 8.13:1 around the yellow button.
- **Checked controls are yellow in both themes**: radio, checkbox and switch.
- **Text on yellow is dark gray in both themes**: the new token `brand-yellow-ink` (8.13:1), used by the primary button, the check mark, the selected day, the notification count and the solid primary badge.
- **The brown stays in four places**: the knob of a switch that is on, the center of the `Slider` thumb, the play button of `MediaEmbed` and the selected item of a solid `BottomNav` (`circle-bold`, `capsule`, `expand`). The new token is `primary-mark`.
- **The radio dot is white** (the new token `control-selected-dot`).
- **The `MediaEmbed` play button** has no dark ring, and the video box has no dark 1px edge around the cover.
- **The outline primary badge** writes in the pure yellow, the same as the soft one.
- **`AppShell layout="docs"` on phones and tablets**: on phones the drawer button comes last and the drawer opens from the right. Below 1280px a 40px table-of-contents bar sits under the header, shows the section in view and opens the list. From 768px the sidebar is a column.

## Fixed

- **`DependencyGraph`: mouse clicks on a node reach `onSelect` outside the editable mode.** Before, with only `onSelect` (no `editable`, no `onNodeHover`), a mouse click on the node body did nothing (the keyboard worked), and the collapse button ignored the mouse.
- **`DependencyGraph`: `layer` works in the `layered` layout.** Nodes with the same `layer` sit at the same height, and the layers follow the order given. `layer` is an order, not a number (0, 5 and 10 become the 1st, 2nd and 3rd layer). It applies when every node outside a container has one; with `layer` on only some nodes, the graph is laid out as without layers and warns once in the console.
- **`Radio`: the checked dot is centered.** It was half a pixel up and to the left at every zoom level. It is now 6px inside the 14px center.
- **`Prose`: inline code wraps**, so a long `code` in a paragraph no longer pushes the page sideways on phones.

## Breaking changes

- **`layer` in `DependencyGraph` now changes the layout** if you already pass it on every node: until v0.35.0 it was ignored.
- **Nine color tokens have new values.** In the light theme: `primary-emphasis`, `primary-outline`, `link`, `link-hover`, `focus-strong` and `control-selected`. In both themes: `primary-foreground`, `sidebar-primary-foreground` and `control-selected-foreground` (brown to dark gray). If your own screens use these tokens, they get the new colors; the accent text in the light theme no longer reaches 4.5:1. `brand-yellow-text` still exists.
- **`AureaStrings` (web) has eleven new keys** for the cookie notice: `consentTitle`, `consentReject`, `consentAccept`, `consentChoose`, `consentPreferences`, `consentSave`, `consentRequired`, `consentAccepted`, `consentRejected`, `consentSaved` and `consentHide`. If you build the whole object yourself (your own translation), add them.
