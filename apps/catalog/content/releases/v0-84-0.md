## Fixed

- **Shift-click on `Checkbox`, `CheckboxGroup`, `Radio`, `RadioGroup`, `Switch` and the `DataGrid` selection column now works** in Chrome, Edge and Firefox, as it already did in Safari. Before, holding Shift and clicking the box selected text instead of checking it. The hidden input now covers the whole label and takes the click. Nothing changes on screen. The same applies to plain HTML with the `.checkbox`, `.radio` and `.switch` classes.
- **A link or button inside the label** ("I accept the terms") still works as a link and does not check the box.
