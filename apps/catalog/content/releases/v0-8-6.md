Two additions for React Native. `SegmentedControl` and `Tabs` scroll sideways when their options do not fit the screen, and show a scroll bar only when there is more to see. `Card` gains a `brand` variant, the first large surface filled with the brand yellow.

## New

### React Native

- **[`SegmentedControl`](./segmentedcontrol.html) and [`Tabs`](./tabs.html) scroll sideways when they do not fit**, as the web already did on small screens. The cut-off option at the edge plus a scroll bar tell you there is more; the scroll bar appears only when the content actually overflows.
- **[`Card`](./card.html) `variant="brand"`**: a card filled with the brand yellow. The text color inside is forced to `primary-foreground`, because normal and muted text do not read on the yellow in the dark theme. Inside it there is a single text color; hierarchy comes from weight and size.
- **`variant="brand"` requires `action`**: the brand card is meant for asking the user to do something, so it does not compile without an action.

## Fixed

### React Native

- **`Tabs`: the tab row scrolled without showing that more tabs existed.** The scroll indicator was turned off in v0.8.5, so anyone who did not think to swipe never found the hidden tabs. `Tabs` and `SegmentedControl` now share the same scrolling piece.
