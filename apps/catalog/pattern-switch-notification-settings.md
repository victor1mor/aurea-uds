# Notification settings

Flip and it is done. No Save button — that is what makes it a Switch and not a Checkbox.

## Usage

```tsx
import {Card, Switch} from "@aurea-uds/react";
```

```tsx
<Card>
  <strong>Notifications</strong>
  <Switch label="Email" defaultChecked />
  <Switch label="Push" />
  <Switch label="Weekly digest" defaultChecked />
</Card>
```
