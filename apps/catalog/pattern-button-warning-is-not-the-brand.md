# Warning is not the brand

Amber, not the Aurea yellow. Until August 2026 the warning token resolved to the brand colour in dark theme — same pixels, two different meanings — so warning was not a tone at all. It has its own identity now, picked by measuring perceptual distance from both neighbours: the brand on one side, the destructive red on the other.

## Usage

```tsx
import {Button} from "@aurea-uds/react";
```

```tsx
<Button appearance="solid" tone="warning" leadingIcon="warning">Revoke access</Button>
<Button variant="primary">Publish</Button>  {/* a marca, ao lado */}
```
