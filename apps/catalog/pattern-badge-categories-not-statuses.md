# Categories, not statuses

Eight colour names mark a group — a section, a kind of item — and say nothing about health, so they never compete with success or danger. Yellow is left out: it belongs to the brand. The word and the icon carry the meaning; the colour only helps the eye find the group again.

## Usage

```tsx
import {Badge, Icon} from "@aurea-uds/react";
```

```tsx
<Badge variant="blue" leading={<Icon name="code" />}>Engineering</Badge>
<Badge variant="violet" leading={<Icon name="palette" />}>Design</Badge>
<Badge variant="orange" leading={<Icon name="megaphone" />}>Marketing</Badge>
<Badge variant="green" leading={<Icon name="coins" />}>Finance</Badge>
```
