# A button that stays pressed

Two states the user flips and reads back from the button itself. It is not a Switch: a switch applies a setting, a toggle marks the thing under the cursor.

## Usage

```tsx
import {Toggle} from "@aurea-uds/react";
```

```tsx
<Toggle icon="text-b" label="Bold" defaultPressed />
<Toggle icon="text-italic" label="Italic" />
```
