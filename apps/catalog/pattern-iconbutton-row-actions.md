# Row actions

The trio at the end of a table row: open, edit, delete — quiet until the row matters.

## Usage

```tsx
import {ButtonGroup, IconButton} from "@aurea-uds/react";
```

```tsx
<ButtonGroup label="Row actions">
  <IconButton icon="eye" label="Open" />
  <IconButton icon="pencil-simple" label="Edit" />
  <IconButton icon="trash" label="Delete" variant="danger-ghost" />
</ButtonGroup>
```
