# A number with its comparison

The delta only means something next to a period, so the trend line carries both. A KPI without a comparison is a number on a wall — true, and useless for deciding anything.

## Usage

```tsx
import {KPI} from "@aurea-uds/react";
```

```tsx
<KPI label="Runs" value="1,284" trend="+12% vs last week" />
```
