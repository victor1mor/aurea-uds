# Segmented range

Coordinated set of the same control. Each button stays tabbable — that is what separates it from a Toolbar.

## Usage

```tsx
import {ButtonGroup, Button} from "@aurea-uds/react";
```

```tsx
<ButtonGroup label="Range">
  <Button>Day</Button>
  <Button>Week</Button>
  <Button>Month</Button>
</ButtonGroup>
```
