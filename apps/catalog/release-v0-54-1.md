# v0.54.1

A shorter field for the large CommandPalette.

One visual change to a component; nothing else in the packages moves.

## Changed

- **`CommandPalette size="lg"`** — the search field is now 52 tall instead of 64. The window, the filters, the items and the preview stay the same.

On React Native:
