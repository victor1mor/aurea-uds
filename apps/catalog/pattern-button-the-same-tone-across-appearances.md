# The same tone across appearances

One tone, four weights — and every cell exists. A tone never loses its filled form: each one owns a colour and the text colour that goes on top of it, chosen per theme and verified for AA contrast, exactly as the destructive tone always had.

## Usage

```tsx
import {Button} from "@aurea-uds/react";
```

```tsx
<Button appearance="solid" tone="success">Approve</Button>
<Button appearance="outline" tone="success">Approve</Button>
<Button appearance="ghost" tone="success">Approve</Button>
<Button appearance="link" tone="success">Approve</Button>
```
