# With caption

The caption names the table for a screen reader and for the eye — a table with no name is a grid of noise.

## Usage

```tsx
import {Table} from "@aurea-uds/react";
```

```tsx
<Table caption="Workspace members">
  <thead><tr><th>Name</th><th>Plan</th></tr></thead>
  <tbody>…</tbody>
</Table>
```
