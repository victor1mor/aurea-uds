# Security

## Supported versions

Only the latest version published on npm receives security fixes. The current version is in the
[`CHANGELOG.md`](CHANGELOG.md).

## How to report a vulnerability

**Do not open a public issue.** Use GitHub's *private vulnerability reporting*: on the repository's
**Security** tab, **Report a vulnerability**. Only the maintainer reads it.

Please include:

- which package and which version (`@aurea-uds/react`, `@aurea-uds/native`…);
- what the vulnerability allows;
- how to reproduce it, with the smallest possible example.

If the vulnerability is confirmed, the fix ships in a new version, and the report becomes public after
it, crediting the reporter if they wish.
