# Segurança

## Versões cobertas

Só a versão mais recente publicada no npm recebe conserto de segurança. A versão atual está no
[`CHANGELOG.md`](CHANGELOG.md).

## Como relatar uma falha

**Não abra um problema público.** Use o relato privado do GitHub: na aba **Security** do
repositório, **Report a vulnerability**. Só o mantenedor lê.

Diga:

- qual pacote e qual versão (`@aurea-uds/react`, `@aurea-uds/native`…);
- o que dá para fazer com a falha;
- como reproduzir, com o menor exemplo possível.

Se a falha for confirmada, o conserto sai numa versão nova, e o relato fica público depois dela,
com crédito a quem relatou, se a pessoa quiser.
